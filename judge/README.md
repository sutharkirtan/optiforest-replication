Blinded LLM-as-judge check (see Appendix of the report). `judge_key.json`: file names and construction labels per row id; `judge_output.json`: the judge's 1-10 scores and short reasons. The judge's input (rounded Credit Card rows) is not included because Credit Card-derived data are not redistributed; `scripts/build_judge_inputs.py OUTDIR 7` regenerates it from your own copy of the data (it will produce the same rows when the constructed files are regenerated with seed 42). `scripts/score_judge.py JUDGE_DIR` recomputes `results_llm_judge.json`.

Notes: the judge was a Claude subagent whose exact model version was not recorded; the exact prompt wording was not saved verbatim (the report's Appendix B gives its substance), so the check cannot be rerun identically. Row-level scores and reasons are in `judge_output.json`.
